# Windows Server Home Lab

## Overview
A practical home lab focused on Windows Server administration, Active Directory and IT support.

## Lab Environment
- Oracle VirtualBox
- Windows Server
- Windows client machines

## Implemented Features
- Active Directory users, groups and Organizational Units (OUs)
- Domain-joined Windows clients
- SMB file sharing
- Group Policy Objects (GPO)
- Network drive mapping using GPO

## Technologies
- Windows Server
- Active Directory Domain Services (AD DS)
- Group Policy Management
- SMB
- DNS and DHCP

## Next Steps
- Document configurations with screenshots
- Practice troubleshooting scenarios
- Learn PowerShell automation
- Explore advanced GPO configurations

## Project Goal
Develop practical skills for IT Helpdesk, L1/L2 Support and Junior System Administrator roles.
